# Контур валидации стратегий — как запустить

**Подаём:** `*_candles.csv` (выгрузка `services/run_validation.py` из
`market_data_session` в `VALIDATION_DATA_DIR`), издержки — поштучно из
`audit/out/cost_matrix.csv` (`services/cost_model.py`).
**Запускаем:** в составе ETL автоматически; вручную из `strategy_validation/`:
`python -m validation.verdict --tickers etln selg --strats long_overnight intraday_short --data-dir <каталог>`
**Получаем:** вердикт на пару (бумага, стратегия): REJECTED / WEAK / CANDIDATE EDGE —
White RC, SPA, PBO, BH-FDR, OOS-хвост.
**Самопроверка:** `python advanced_stats.py --mode selftest`; модули
`validation/*.py` запускаются как самотесты (`python -m validation.bootstrap` и т.д.).
