Проект закрыт 11.10.2026 решением владельца. Здесь — **результаты и отчёты**; сырые данные
не сохранялись (решение владельца), сервер очищен.

## Итог в одной строке
**294 предрегистрированных испытания — ни одна стратегия не обыграла денежный рынок (ключевую
ставку / фонд TMON) после издержек на отложенной выборке.** Реальные, но не торгуемые эффекты:
прогноз волатильности HAR-RV, аномалия низкой волатильности, внутридневная реверсия, новостная
метка markettwits, ранжирование облигаций по спреду, отставание свежих криптолистингов от BTC.
