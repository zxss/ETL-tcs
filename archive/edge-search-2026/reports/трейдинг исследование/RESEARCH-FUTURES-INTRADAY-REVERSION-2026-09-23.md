# Внутридневная реверсия на фьючерсах — отвергнута

Приоритет №2 из инвентаризации 23.09.2026. Предзарегистрированный тест на VDS,
код `research/futures/intraday_reversion.py`. Реестр испытаний: +10, всего **198**.

## Гипотеза (заморожена до прогона)

На акциях нашлась реальная (но не торгуемая из-за издержек) внутридневная
реверсия: аномальный часовой ход откатывается к закрытию сессии. У фьючерсов
издержки относительно хода ниже — проверяем, не станет ли эффект торгуемым.
Инструменты BR/NG/GD/Si/MX, ближний контракт по объёму вчера, сессия 10:00–18:45,
z-оценка часового хода к собственной истории окна, правило контрариан
(|z|≥2 → фейд хода, выход на закрытии), издержки круга 0,02 % и 0,05 %.
dev 2024-05-21…2026-09-11, holdout 2022-01-03…2024-05-20.

## Результат — реверсии нет; правило-фейд убыточно, значимо

**Пулинг-корреляция z(часовой ход) ↔ откат до закрытия:**

| инстр. | dev r (t, Холм) | holdout r (t) |
|---|---|---|
| Brent | +0,019 (1,41, Холм 0,47) | +0,006 (0,38) |
| газ NG | +0,014 (1,04, 0,60) | −0,012 (−0,79) |
| золото $ | +0,003 (0,23, 0,82) | −0,019 (−1,28) |
| USD/RUB | +0,034 (2,35, 0,095) | −0,010 (−0,71) |
| индекс MOEX | +0,028 (2,09, 0,15) | **−0,072 (−4,88)** |

**Правило-фейд (наша гипотеза реверсии), нетто/день:**

| инстр. | dev (изд. 0,05 %) | holdout (0,05 %) |
|---|---|---|
| USD/RUB | −0,145 % (t **−4,68**) | −0,097 % (−1,34) |
| золото $ | −0,100 % (t **−3,14**) | −0,049 % (−1,72) |
| индекс MOEX | −0,105 % (t −2,49) | −0,049 % (−0,73) |
| Brent | −0,058 % (−0,89) | −0,130 % (−1,76) |
| газ NG | −0,143 % (−1,31) | +0,015 % (+0,11) |

Два вывода:
1. **Реверсия на фьючерсы не переносится.** Знак пулинг-корреляции на dev
   ПОЛОЖИТЕЛЬНЫЙ (слабый моментум/продолжение), а не отрицательный, как на
   акциях. Правило-фейд, которое ставит на откат, теряет деньги — значимо на
   USD/RUB (t −4,68), золоте (t −3,14), индексе (t −2,49). То есть ход
   фьючерса скорее ПРОДОЛЖается, чем откатывается.
2. **Но и моментум нестабилен — эффекта нет.** Намёк на моментум на dev (Si,
   MX) не проходит поправку Холма (0,095 / 0,15) и на holdout разваливается:
   USD/RUB исчезает (+0,034 → −0,010), индекс MOEX ПЕРЕВОРАЧИВАЕТ знак
   (+0,028 → −0,072). Знак не стабилен между выборками — это переподгонка/шум,
   а не эффект.

Замечание про моментум сделано ПОСТ-ФАКТУМ (предзарегистрирована была реверсия);
раз он к тому же не держится на holdout, отдельной гипотезой его не оформляем.

## Вывод

Приоритет №2 закрыт отрицательно. Реверсия, реальная на акциях, на фьючерсах не
воспроизводится; устойчивого сигн-стабильного внутридневного эффекта на
BR/NG/GD/Si/MX нет. Вместе с приоритетом №1 (новости→Brent, тоже минус) это
закрывает оба намеченных направления по фьючерсам. Незакрытым остаётся только
кросс-активный lead-lag между самими фьючерсами (Brent↔газ, USD/RUB↔нефть) —
если решишь копать дальше.
