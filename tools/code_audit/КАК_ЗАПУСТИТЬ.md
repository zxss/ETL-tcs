# Аудит кода — как запустить

**Подаём:** рабочее дерево git (отслеживаемые `*.py`, `config.py`, `.env.example`,
расписания в `scripts/*crontab*`, `FLOWS.md`, все `КАК_ЗАПУСТИТЬ.md`).
**Запускаем:** `python -m tools.code_audit.audit`
**Получаем:** `audit/out/code_audit_wNN.json` (все находки, параметры, самопроверки)
и `audit/out/code_audit_wNN.md` (сводка). Версии не перезаписываются. В stdout —
только число находок по разделам и путь к сводке: большой JSON в контекст не грузить.

**Что ищет:** расхождение умолчаний `getattr(config, …)` с `config.py`; ключи
окружения без описания в `.env.example`; точки входа, не описанные в `FLOWS.md` /
`КАК_ЗАПУСТИТЬ.md` / разделе «Архив»; модули, которые никто не импортирует;
одинаковые тела функций в разных файлах; перезапись артефактов в `audit/`,
`research/`, `tools/` без версии; абсолютные пути; функции > 150 строк; TODO.

**Самопроверка:** число разобранных файлов сходится с `git ls-files`; нет ошибок
разбора; итоги сводки равны длинам списков. Провал — код выхода 1.

**Исправить автоматически:**
- умолчания getattr → `python -m tools.code_audit.fix_getattr --dry-run`, затем без флага
  (правит однострочные вызовы по последнему JSON, откатывает правку, если код не
  компилируется); после — снова аудит и тесты;
- `.env.example` → `python -m tools.env_example_sync`.
