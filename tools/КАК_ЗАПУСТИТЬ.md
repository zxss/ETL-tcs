# Инструменты потоков — как пользоваться

## tools/flowkit.py — версии и самопроверка для любого скрипта-потока

```python
from tools.flowkit import Checks, versioned, save_state
chk = Checks("мой-поток")
chk.close("сумма по годам = итог", sum(by_year), total, tol=1e-9)   # независимый пересчёт
out = versioned("audit/out", "мой_результат", "json")              # …_w03.json, старые целы
save_state(out, params=PARAMS, results=res, checks=chk, inputs={"data": path})
print(chk.report()); raise SystemExit(chk.exit_code())
```
Тесты: `python -m unittest tests.test_flowkit`.

## tools/env_example_sync.py — описание ключей окружения

`python -m tools.env_example_sync` — дописывает в конец `.env.example` закомментированный
авто-блок с ключами, которые читает код, но нет выше; умолчания — из `config.py`.
`--check` — только проверить (код 1, если блок устарел). Блок руками не править.
