# Исследовательское испытание

Программа: 286+ испытаний, ставку ЦБ не обыграло ничто. Каждое новое испытание
поднимает порог значимости — не тратить испытания на то, что закрыто (память
проекта и `~/Desktop/трейдинг исследование/RESEARCH-*.md`).

## Порядок
1. **Осуществимость дёшево.** Есть ли данные и ликвидность — описательный замер без
   подбора параметров (не испытание).
2. **Предрегистрация до данных:** `research/<тема>/PREREG.md` — структура, параметры,
   выборки (разработка / отложенная), издержки ×1 и ×2, метрики, порог «реальные деньги».
   Закоммитить ДО первого просмотра данных — время коммита доказывает порядок.
3. **Скрипт строго по PREREG**, закоммичен до запуска. Самопроверка — `tools.flowkit.Checks`
   (пересчёт итогов, сверка числа циклов); результат — `versioned(...)` + `save_state`.
   Проверить численные части на синтетике до реальных данных.
4. **Запуск один раз.** Параметры после просмотра не менять — это новое испытание.
   Ошибка разбора данных (не параметров) исправляется открыто: отдельный коммит
   «ИСПРАВЛЕНИЕ …», первый результат сохраняется и раскрывается в отчёте.
5. **Реестр:** номер испытания, `n_trials` для DSR = прежние + новые; поправка Холма
   внутри испытания.
6. **Отчёт** — `~/Desktop/трейдинг исследование/RESEARCH-<ТЕМА>-<дата>.md`, данные рядом;
   запись в память проекта.

## Порог «реальные деньги» (по умолчанию)
t ≥ 2 на полной выборке; знак сохраняется на разработке И отложенной; Холм p < 0,05;
DSR ≥ 0,95 на полном числе испытаний; знак сохраняется при издержках ×2.

## Данные и ловушки
- ISS Мосбиржи (публичный): `/iss/history/engines/futures/markets/options/securities.json`
  с `assetcode=RTS|Si`, страница ≤ 100 строк; серии и фьючерсы старше ~10 лет — с
  суффиксом года (`RI100000BA5_2015`, `RIH4_2014`).
- Длинная история акций с дивидендами — `/opt/etl-r4/audit/r4_research/longhist`.
- 5-минутки не скорректированы на сплиты (VTBR 5000:1, FIXR) — дневные скорректированы.
- Издержки — `services/cost_model.py` / `audit/out/cost_matrix.csv`; маржинальный
  кредит ~27–35 %/год, плечо — только фьючерсами.
