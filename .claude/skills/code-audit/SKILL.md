# Аудит кода

1. `python -m tools.code_audit.audit` — в контекст брать только stdout (счётчики) и
   нужные разделы `audit/out/code_audit_wNN.md` через `awk '/^## Раздел/,/^## /'`.
   JSON целиком не читать.
2. Самопроверки провалены → сначала чинить детектор, потом верить находкам.
   Ложные срабатывания («мёртвый» модуль с относительным импортом, рабочее состояние
   в `services/`) — исправлять в `tools/code_audit/audit.py`, а не игнорировать.
3. Исправления скриптами:
   - умолчания getattr → `python -m tools.code_audit.fix_getattr` (сначала `--dry-run`);
   - `.env.example` → `python -m tools.env_example_sync`;
   - точки входа → строка в `FLOWS.md` (поток) или в разделе «Архив»; у потока —
     `КАК_ЗАПУСТИТЬ.md`;
   - перезапись артефактов → `tools.flowkit.versioned` + `save_state`.
4. После правок — повторный аудит (новая версия `_wNN`) и `python -m unittest discover -s tests`.
   Локально 5 падений `TestRetryOn429` — артефакт Python 3.9; на сервере (3.14) всё зелёное.
