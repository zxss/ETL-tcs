# Предрегистрация: криптовалюта — тренд, кросс-секционные факторы, листинги (испытания № 290–294)

Зафиксировано 10.10.2026 ДО загрузки истории цен. Просмотрено только: доступность API
(по две последние свечи ETHUSDT и TONUSDT, без расчёта доходностей). Запрос
пользователя: «проанализировать крипту, включая телеграм-токены и эфириум, найти токены
с потенциалом роста, прогнать модели на торговлю криптовалютой». Программа до этого —
289 испытаний, ни одно не обыграло денежный рынок.

## Данные
* **Binance spot, пары к USDT, дневные свечи** из архива `data.binance.vision`
  (`data/spot/monthly/klines/<SYMBOL>/1d/`). Список символов — из листинга S3-бакета,
  поэтому в выборке есть и делистингованные монеты (без отбора выживших).
* Исключаются: стейблкоины и фиат (USDC, FDUSD, TUSD, BUSD, DAI, USDP, PAX, UST, EUR,
  AEUR, GBP, TRY, BRL и т. п.), обёрнутые (WBTC, WBETH, BETH), плечевые токены
  (*UP/*DOWN/*BULL/*BEAR).
* Период 2019-01-01 … 2026-09-30. **Разработка 2019-01 … 2023-12, отложенная
  2024-01 … 2026-09.** Время — UTC, день = свеча 00:00–24:00 UTC.
* Телеграм-токены (экосистема TON и тап-игры): TON, NOT, DOGS, HMSTR, CATI и другие,
  если есть на Binance; вне Binance — только описательно (GeckoTerminal / KuCoin / Gate).

## Вселенная на дату t (для № 291–293)
Пара входит, если на t: ≥ 60 дней истории и медиана дневного оборота в USDT за 30 дней
≥ 5 млн $. Веса внутри портфелей равные.

## Издержки
BTC и ETH — 0,1 % на сторону, остальные — 0,2 % на сторону (комиссия 0,1 % + спред и
проскальзывание). Списываются с оборота. Чувствительность ×2. Денежная часть — 0 %
(USDT без процента): консервативно.

## Испытания
**№ 290 — тренд (time-series momentum) по BTC и ETH.** Держим монету, если её доходность
за 90 дней > 0, иначе деньги; решение по закрытию дня, исполнение на следующем закрытии.
Метрика по каждой монете: среднедневной результат стратегии (t), коэффициент Шарпа
стратегии против «купи и держи». Успех: стратегия > 0 с t ≥ 2 И Шарп выше, чем у
«купи и держи», на разработке И на отложенной, у обеих монет.

**№ 291 — кросс-секционный моментум альтов.** Каждый понедельник: доходность за 28 дней,
кроме последнего дня; лонг верхнего квинтиля, держание неделя. Метрика — недельный
избыток лонг-портфеля над равновзвешенной вселенной после издержек.

**№ 292 — краткосрочная реверсия.** То же, сигнал — доходность за последние 7 дней,
лонг НИЖНЕГО квинтиля. Метрика — недельный избыток над вселенной.

**№ 293 — низкая волатильность.** То же, сигнал — реализованная волатильность дневных
доходностей за 30 дней, лонг нижнего квинтиля. Метрика — недельный избыток над вселенной.

Порог для № 291–293: избыток > 0, t ≥ 2 на полной выборке, знак сохраняется на
разработке И на отложенной, Холм p < 0,05 внутри трёх, DSR ≥ 0,95 при 294 испытаниях,
знак сохраняется при издержках ×2.

**№ 294 — монеты после листинга.** Для каждой пары с первой свечой с 2021-01-01:
доходность с закрытия 7-го дня торгов по закрытие 97-го (90 дней) минус доходность BTC
за те же даты. Гипотеза: новые листинги в среднем отстают от BTC (выход эйрдропов и
разлоков). Успех: средний избыток < 0 с t ≤ −2 на полной выборке и знак отрицательный у
листингов 2021–2023 И 2024–2026. Телеграм-токены — отдельная строка, описательно
(их мало для статистики).

## Что выдаём
Отчёт: итоги № 290–294; текущий срез «кто сейчас в лонге по прошедшим проверку
сигналам». Если ни один сигнал не прошёл — срез только описательный (моментум, оборот,
капитализация и FDV по CoinGecko) с пометкой «не прогноз». Отдельно — описательная
сводка по ETH и телеграм-токенам.

## Что НЕ делаем
Нейросеть TFT на крипте не обучаем: на акциях вне выборки IC ≈ 0 (№ ~280). Плечо и
шорт (бессрочные фьючерсы) не тестируем: нет истории ставок финансирования в архиве
этого испытания.
