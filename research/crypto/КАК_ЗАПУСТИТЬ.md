# Крипта: данные, испытания № 290–294, срез рынка

## Что подаём
Ничего — публичные данные Binance (`data-api.binance.vision`, отдаёт и делистинговые пары; архив
`data.binance.vision` — запасной путь), CoinGecko, GeckoTerminal. Ключей не нужно.

## Что запускаем
```
python -m research.crypto.download --out <DATA>            # 678 пар, ~5 минут, 57 МБ
python -m research.crypto.trials   --data <DATA>           # № 290–294 строго по PREREG.md — ОДИН раз
python -m research.crypto.screen   --out <DATA>/results --trials <DATA>/results/crypto_trials_w01.json
```
На сервере: `/opt/research-crypto` (код), `<DATA>` = `/opt/research-data/crypto`, venv `/opt/etl-tcs/.venv`.

## Что получаем
* `<DATA>/daily/<SYMBOL>.csv` — дневные свечи; `symbols.json` — список и исключённые.
* `<DATA>/results/crypto_trials_wNN.json` — испытания, самопроверки, недельные ряды, листинги.
* `<DATA>/results/crypto_screen_wNN.json` — срез на сегодня (описательно, не прогноз).
