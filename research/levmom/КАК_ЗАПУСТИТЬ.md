# Моментум с плечом на фьючерсах — как запустить

**Подаём:** длинная история акций с дивидендами (`/opt/etl-r4/audit/r4_research/longhist`),
MCFTR и ставка ЦБ (ISS, cbr.ru); для рукава — БД `market_data` + `dividends` и API песочницы.

1. Бэктест и выбор плеча:
   `cd /opt/research-vrp && python -m research.levmom.backtest`
   → `/opt/research-data/levmom/levmom_backtest_wNN.json`; плечо — максимум по двум
   ограничениям (ГО ≤ 75 % капитала; без маржин-колла в худший исторический месяц).
2. Рукав в ПЕСОЧНИЦЕ (расписание `/etc/cron.d/etl-levmom`, по будням):
   - `python -m research.levmom.sleeve rebalance --if-due` — ребаланс раз в месяц (10:15);
   - `python -m research.levmom.sleeve check` — ролл и разгрузка ГО (10:25, 18:30);
   - `python -m research.levmom.sleeve status` — капитал, позиции;
   - любую команду можно с `--dry-run` (план без заявок).
   Журнал: `/opt/research-data/levmom/{ledger,daily}.jsonl`, `cron.log`, счёт — `account.txt`.

**Самопроверка бэктеста:** выбранное плечо не выше ограничений; тождество «без плеча
доходность = ставка»; t спреда пересчитан.
Только песочница: боевого пути в модуле нет, чужие счета отклоняются.
Отчёт: `~/Desktop/трейдинг исследование/RESEARCH-LEVERAGED-MOMENTUM-2026-09-27.md`.
