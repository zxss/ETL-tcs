# Портфель ВДО (облигации повышенной доходности)

Только **песочница** T-Invest, отдельный счёт (`$BONDS_DIR/account.txt`). Боевого
пути в коде нет: клиент — `TinkoffSandboxClient`, счета других контуров (боевой, r4,
levmom, старый моментум-рукав) отклоняются.

## Что подаём
* **Правила** — последняя `bonds/rules_wNN.json`. Меняет их пользователь: правка —
  новая версия файла (`rules_w02.json` …), старые не переписываются.
* **MOEX ISS** — текущий срез доски TQCB (доходность к оферте/погашению, цена в % номинала,
  НКД, дюрация, стакан, даты оферт), история по датам (оборот за 10 торговых дней,
  бэктест), календарь торговых дней по индексу RUCBTRNS.
* **T-Invest API** (`InstrumentsService/Bonds`) — торгуемость через API, «только для
  квалов», нужен ли тест, плавающий купон, субординация, бессрочность, сектор, объём
  выпуска, лот, номинал, шаг цены, рейтинги агентств с прогнозом и «на пересмотре».
* **smart-lab** (`/q/bonds/`, 16 страниц, пауза 2 с, кэш на день) — рейтинг для сверки
  и эмитент (slug). Берётся **худший** из рейтингов брокера и smart-lab.
* **Ключевая ставка ЦБ** — `macro_rates` в БД, при пустой таблице — прямо с сайта ЦБ.

## Что запускаем
```
cd /opt/etl-bonds && export BONDS_DIR=/opt/research-data/bonds
.venv/bin/python -m bonds.trader rebalance --dry-run   # цель месяца, заявки не ставятся
.venv/bin/python -m bonds.trader rebalance --if-due    # раз в месяц (крон 10:40 будни)
.venv/bin/python -m bonds.trader monitor               # выходы и дозаявки (15:00, 17:30)
.venv/bin/python -m bonds.trader status                # стоимость, структура, лимиты
.venv/bin/python -m bonds.trader flags --out flags.json
.venv/bin/python -m bonds.backtest --cache $BONDS_DIR/cache --flags $BONDS_DIR/flags.json
```
Крон — `/etc/cron.d/etl-bonds`. Выкладка: `git archive feature/bonds` → `/opt/etl-bonds`,
`.env` и `.venv` — симлинки на `/opt/etl-tcs`, коммит — в `REVISION`.

## Что получаем
* `target_YYYY-MM_wNN.json` — цель месяца: веса, отобранные выпуски, причины
  исключения, самопроверки ограничений. Версии не перезаписываются.
* `ledger.jsonl` — каждый боевой (для песочницы) запуск: заявки, статусы, выходы.
* `cache/results/bonds_backtest_wNN.json` — бэктест по `bonds/PREREG.md` (испытание № 287).

## Логика
1. Фильтры (`core.exclusion_reason`): рубли, без квал/тестов/флоатеров/субординации/
   бессрочных, выпуск ≥ 300 млн ₽, до оферты/погашения ≥ 60 дней, спред к ставке
   3…15 п.п., цена 85–105 %, дюрация 0,3–2,5 года, оборот ≥ 1 млн ₽/день (медиана 10 дней),
   спред стакана ≤ 1 %, рейтинг BB-…A-, без негативного прогноза.
2. Ранг — доходность минус медиана своей рейтинговой корзины (дешевизна к рейтингу).
3. Отбор — 20 выпусков по 4,75 %, ≤ 5 % на эмитента, ≤ 25 % на сектор, дюрация
   портфеля ≤ 2, резерв 5 % деньгами; удерживаемые бумаги в топ-40 остаются (меньше оборота).
4. Заявки — лимитные, только при `NORMAL_TRADING`, цена в % номинала: покупка по
   лучшему ask, но не выше last + 0,5 %; продажа зеркально; сперва продажи.
5. Ежедневно — выход при цене < 80 %, оферте/погашении < 30 дней, понижении рейтинга
   ниже BB-, негативном прогнозе, остановке торгов. Вышедшая бумага не докупается до
   следующего ребаланса.

## Подводные камни
* Цена облигации в API и ISS — **% номинала**; стоимость штуки = цена/100 × номинал + НКД.
* На MOEX есть сессия выходного дня: статус `NORMAL_TRADING` в субботу/воскресенье
  настоящий, но стакан тонкий — поэтому крон только по будням.
* RUCBITR в ISS оборван 31.05.2023 — календарь по RUCBTRNS, обрыв ловит самопроверка.
* Бэктест идёт без кредитного фильтра (истории рейтингов нет) — это раскрыто в PREREG.
