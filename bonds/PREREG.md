# Предрегистрация: портфель ВДО по правилам rules_w01.json

Зафиксировано 27.09.2026 ДО выгрузки исторических данных ISS (просмотрены только
текущие срезы для проверки полей: 1 721 корпоративный выпуск с доходностью, медиана
17,1 %). Параметры — `bonds/rules_w01.json`; изменение после просмотра данных — новое
испытание с новым номером.

## Вопрос
Обыгрывает ли диверсифицированный портфель облигаций повышенной доходности,
собранный по правилам, фонд денежного рынка (ключевую ставку) после издержек и
дефолтов?

## Бэктест
* Период: 2021-01 … 2026-08, ежемесячный ребаланс на первый торговый день после
  конца месяца; срез — последний торговый день месяца (ISS history).
* Вселенная и фильтры — rules_w01.json, КРОМЕ кредитного блока (истории рейтингов
  нет): бэктест проверяет правила по доходности, цене, дюрации и ликвидности без
  рейтингового фильтра — это консервативнее живой системы, где рейтинг отсеивает
  часть будущих дефолтов. Корзины для ранжирования — по дюрации (0–1, 1–2, 2–2,5 года).
* Доходность выпуска за месяц: (цена + НКД + выплаченные купоны и амортизация) /
  (цена + НКД на входе) − 1, по дневной истории ISS. Выпуск, переставший торговаться
  (дефолт, делистинг), оценивается по последней цене сделки, после — 0 % до выхода;
  если последняя цена < 50 % номинала, дополнительно −50 % (консервативный возврат).
* Издержки: круг 0,3 % на оборот (в т.ч. 0,08 % комиссии), чувствительность ×2.
* Эталон: ключевая ставка ЦБ за тот же месяц (≈ фонд денежного рынка).

## Метрики и порог «реальные деньги»
Избыточная доходность портфеля над ставкой по месяцам: среднее, t, доля
положительных месяцев, худший месяц, макс. просадка; отдельно 2021–2023 и 2024–2026.
Порог: избыток > 0 с t ≥ 2 на полной выборке; > 0 на обеих половинах; знак
сохраняется при издержках ×2; DSR ≥ 0,95 при числе испытаний программы 287.
